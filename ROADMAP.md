# Roadmap

Delivered in 2.3.0: prop projects from scans, NPC variants (friendly, hostile,
armed hostile), and the localized conformance repair.

## Tier 2, planned next

* **Animation retargeting.** Import community SMD/DMX animation libraries and
  refit them onto the generated ValveBiped skeleton, so characters are not
  limited to the stock m_anm/f_anm sets.
* **Batch export.** Select several finished projects and package them as one
  addon (single folder or GMA) for character packs.

## Later candidates

* Debugging views in the Builder: UV atlas island layout, bake coverage
  heatmap, and a weight/deformation preview per bone.
* Per-material texture size and VTF compression options (DXT vs. uncompressed)
  for finer quality/size control.
* Custom bone-name mapping for GLBs that arrive with non-standard rigs.
* One-click shareable install packs for non-technical users.
